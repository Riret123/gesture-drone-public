# Управление дроном жестами

Прототип: камера → OpenCV/MediaPipe → ROS 2 `/flight_cmd` → MAVROS → ArduPilot.
Открытая ладонь запрашивает GUIDED, арминг и взлёт на 2 м; кулак — посадку.
Дребезг фильтруется пятью кадрами; при потере подтверждённого жеста предусмотрены
hold через 2 с и land через 5 с. Ограничения описаны в [SAFETY.md](docs/SAFETY.md).
Это управление по жестам, а не доказанная автономная навигация.

Новые независимые Python-модули моделируют посадку на мобильную площадку,
колёсный ровер, протокол, геозону, батарею, арбитраж, deadman, фильтры и PID.
Они не подключены к реальному управлению полётом. Прошивка ровера отключена.
Web/Quest-интерфейсы только показывают данные; сервер выдаёт mock-телеметрию.

Для Windows/Linux с Python 3.12 без сторонних зависимостей:

```text
python -B tests/run_all.py
python -B tools/simulate_landings.py
```

Для локального dashboard задайте PYTHONPATH=src/gesture_control, затем выполните
`python -B -m gesture_control.mock_server`; адрес http://127.0.0.1:8081.
Полная английская инструкция: [README.md](README.md). Linux/ROS/SITL:
[TESTING_ON_BOARD.md](docs/TESTING_ON_BOARD.md). Версии зависимостей и проводка
физического контроллера здесь не подтверждены.

Не армить настоящие моторы. Для осмотра стенда снять пропеллеры и отключить питание
моторов; снятие пропеллеров не разрешает арминг. Интеграционный тест — только SITL
с физической изоляцией настоящих контроллеров. Unit-тесты не доказывают безопасность.
План: [ROADMAP.md](docs/ROADMAP.md); архитектура: [ARCHITECTURE.md](docs/ARCHITECTURE.md).
