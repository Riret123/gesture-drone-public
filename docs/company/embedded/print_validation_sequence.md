# R04 E05 - print validation sequence
First validate symbolic dimensions and hole layout. Then render the OpenSCAD design at parameter extremes, inspect visual geometry, export a non-source test model, and measure an unpowered fit coupon before a complete print. Record printer, material, orientation, layer height, wall strategy and actual measured tolerances.

Fit success does not establish strength. Define expected loads, vibration, temperature and fastening torque before a reviewed structural test. A camera bracket deflection changes extrinsics; recheck calibration after installation and mechanical changes.

OpenSCAD rendering, coupon printing, fit, load and vibration tests remain unavailable here. No load-bearing or flight-ready claim is made.
