# R01 E06 - hardware measurement campaign
Order: identify exact parts/revisions; collect manufacturer evidence; review net/power tables; inspect unpowered fit; verify supply and protection design; obtain separate authorization for any powered component test. This run stops at software and documentation.

Owner records instrument ID and uncertainty for dimensions, voltage and current. Thermal measurements need ambient, airflow, sustained load and steady-state criterion. Time measurements need clock domain, trigger and sampling rate. Retest after configuration changes.

Missing measurements are not zero values. Do not substitute nominal values for measured stall or startup peaks. Preserve raw records outside source control if they contain device identifiers or private imagery; commit only scrubbed summaries.
