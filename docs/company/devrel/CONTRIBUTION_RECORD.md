# Personal contribution record template

Purpose: support an honest resume and interview. Complete this locally; do not include private keys, personal identifiers, school records or credentials.

| Field | Evidence to enter |
| --- | --- |
| Feature / date | actual module and change date |
| Problem understood | failure or user need in your own words |
| Personal implementation | functions, tests or measurements you wrote and can explain |
| AI assistance | design, code generation, review or translation assistance received |
| Review performed | specific correction you made after checking source or tests |
| Reproduction command | exact safe offline command |
| Limitation | one known unsupported assumption |
| Interview explanation | input, decision, failure path and output in 60 seconds |

Do not backfill fabricated ownership. If a generated module has not been understood and independently exercised, say "explored with AI assistance" rather than implying personal mastery. A portfolio can demonstrate learning and review without claiming every line as original work.

Acceptance: another person can reproduce the cited evidence and Emir can explain a malformed-input path without reading a script. Admissions or internship outcomes are unknown.
