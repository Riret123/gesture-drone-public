# Demand validation and rejection gates

Round 02 response to B-01-01. All segment demand remains UNVERIFIED. A gate specifies evidence to collect later through authorized research; it is not permission to contact anyone.

| Segment | Minimum useful observation | Reject or reframe if |
| --- | --- | --- |
| Hobby accessories | a specific measured mounting problem and existing workaround | generic bracket already solves it or use is safety critical |
| Gesture control | learner can explain ambiguity and rejection after an offline lesson | gestures add confusion without educational value |
| Education kits | instructor identifies a curriculum objective and observes learner completion | support/safety requirements exceed the proposed resource |
| Inspection analytics | permissioned representative schema and a reviewer checks conclusions | report cannot distinguish missing data from normal operation |
| Agriculture workflow | researcher identifies an actual data-quality check | proposal requires unvalidated sensor inference or flight service |
| Competitions/grants | current official eligibility and institution participation confirmed | individual/program fit fails or deadline cannot be met |
| YouTube/Patreon | permitted activity and authentic observed audience need | content cadence displaces engineering or authorization unclear |
| Open-source plus kits | software reproducibility and support burden measured first | physical fulfillment or safety review exceeds capacity |
| Freelance services | lawful, bounded scope with objective acceptance | buyer expects flight certification, secret data or unsupported expertise |

No fixed sample size or conversion benchmark is invented. Qualitative evidence can justify another experiment, not a market-size claim. Record negative findings and abandoned offers alongside favorable observations.

Disposition: documentation gap fixed by explicit gates; actual demand verification BLOCKED pending human-authorized research.
