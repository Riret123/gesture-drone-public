Frames, clocks and identities

A waypoint's numbers are not meaningful without a coordinate origin and convention. Mission v1 uses local ENU; this does not establish a calibrated aircraft home. A receive timestamp is not a synchronized sensor timestamp. A vehicle or session identifier is not authentication.

Failure evidence matters

Review how a module treats invalid numbers, booleans masquerading as numbers, duplicate JSON fields, stale observations and mutable snapshots. Ask whether a rejection preserves prior authority or invalidates it. A test should show the intended behavior at a boundary.
